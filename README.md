# 🛒 E-commerce API com Flask

API RESTful para gerenciamento de um sistema de e-commerce, desenvolvida como projeto prático durante o curso **Introdução ao Python com Flask** da **Rocketseat**.

A aplicação permite o cadastro e gerenciamento de produtos, autenticação de usuários e manipulação completa de um carrinho de compras com persistência em banco de dados relacional.

---

## 🚀 Tecnologias Utilizadas

* **[Python 3](https://www.python.org/)**
* **[Flask](https://flask.palletsprojects.com/)** — Microframework web para criação das rotas e requisições HTTP.
* **[Flask-SQLAlchemy](https://flask-sqlalchemy.palletsprojects.com/)** — ORM para modelagem e manipulação do banco de dados SQLite.
* **[Flask-Login](https://flask-login.readthedocs.io/)** — Gerenciamento de sessão e proteção de rotas autenticadas.
* **[Flask-CORS](https://flask-cors.readthedocs.io/)** — Habilitação de Cross-Origin Resource Sharing (CORS).
* **[Postman](https://www.postman.com/)** — Testes e validação dos endpoints da API.
